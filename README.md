# Web Kuis Interaktif

Website kuis interaktif sederhana berbasis HTML, CSS, dan JavaScript murni.

## Fitur Utama
- 10 Soal pengetahuan umum pilihan ganda.
- Waktu pengerjaan 15 detik per pertanyaan dengan animasi timer.
- Pengacakan urutan soal secara otomatis setiap kali kuis dimulai (*Fisher-Yates Shuffle*).
- Penayangan video fullscreen otomatis secara acak saat jawaban salah atau waktu habis.
- Penayangan video hasil akhir khusus jika nilai selain 100.
- Hadiah video rahasia (*Secret*) jika berhasil meraih nilai sempurna 100.
- Tampilan responsif dan modern.

## Cara Menjalankan
Buka file `index.html` langsung menggunakan browser pilihan Anda (Google Chrome, Microsoft Edge, Mozilla Firefox, dll).
